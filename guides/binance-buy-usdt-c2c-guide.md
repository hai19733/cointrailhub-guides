# 币安 C2C 买 USDT

用人民币买 USDT 走的是币安的 C2C 平台（平台撮合、币安托管）。

## 基本流程

1. 进入 C2C → 选「购买 USDT」。
2. 选支付方式（银行卡 / 支付宝 / 微信），挑一个靠谱商家。
3. 按页面金额转账给商家，标记「已付款」。
4. 商家确认收款后，USDT 进入你的账户（现多为现货账户）。

## 安全要点

- 认准「商家」标识与成交率，别脱离平台私下转账。
- 转账备注别写「USDT / 币 / 虚拟币」等敏感词，避免银行卡风控。
- 收款账户名与实名一致，防被冻结。
