# 币安下载：官方入口与三端分流

币安没有唯一一个「下载」入口，按设备分成三端，走错渠道容易下到仿冒 App。核心原则：**只认官方渠道，别用第三方下载站。**

## 三端官方入口

- **安卓（Android）**：官方提供 APK 直装 + Google Play 上架两个官方渠道，大陆用户通常走官网 APK。
- **苹果（iOS）**：App Store 搜索 Binance，开发者显示为 **Binance Switzerland AG**（不是「Binance Inc.」）。
- **电脑（桌面）**：官网提供 Windows / macOS 桌面客户端。

## 防假冒三招

1. 认准官网域名（binance.com），不要点搜索结果里的仿冒链接。
2. 核对开发者名称；安卓 APK 认准官方签名。
3. 下载后用币安官方「Binance Verify」核对。
