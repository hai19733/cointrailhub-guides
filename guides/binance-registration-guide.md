# 币安注册与邀请码

## 注册要点

- 支持手机号或邮箱注册，需要设强密码 + 二次验证。
- 注册后可先浏览，但要交易 / 充提必须先完成 KYC 身份验证。

## 邀请码（返佣）

- 新用户注册时在「邀请码」栏填写，可享现货 / 合约手续费返佣。
- 注册后漏填或填错的，部分情况可通过「补绑」补救，但有条件（新号 30 天内 / 走官方 Recall 链接等），并非所有账号都能补。

## 避坑

- 别信「填码就稳赚」「高额返现」话术；返佣比例以官方实时为准。
- 注册入口只认官网，谨防仿冒站套取账号密码。
